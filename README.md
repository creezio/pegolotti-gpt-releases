# Pegolotti GPT — téléchargements

Ce dépôt public distribue uniquement les installateurs et les mises à jour Windows de Pegolotti GPT. Le code source reste dans un dépôt privé.

Pegolotti GPT fonctionne localement sur le poste Windows, avec le Codex de l’utilisateur. GitHub sert au téléchargement du logiciel ; les conversations ne passent pas par GitHub.

La [version pilote 0.1.23](https://github.com/creezio/pegolotti-gpt-releases/releases/tag/v0.1.23) est disponible : [télécharger l’installateur Windows](https://github.com/creezio/pegolotti-gpt-releases/releases/download/v0.1.23/PegolottiGPT-Setup-0.1.23.exe).

Le paquet, le catalogue embarqué et les contrôles isolés sont vérifiés. La reprise et la recette de l’application installée sur le poste pilote restent à confirmer. Cette version n’est pas publiée comme version stable.

Les versions qualifiées seront disponibles dans [Releases](https://github.com/creezio/pegolotti-gpt-releases/releases).
