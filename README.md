# Pegolotti GPT — téléchargements

Ce dépôt public distribue uniquement les installateurs et les mises à jour Windows de Pegolotti GPT. Le code source reste dans un dépôt privé.

Pegolotti GPT fonctionne localement sur le poste Windows, avec le Codex de l’utilisateur. GitHub sert au téléchargement du logiciel ; les conversations ne passent pas par GitHub.

La [version pilote 0.1.24](https://github.com/creezio/pegolotti-gpt-releases/releases/tag/v0.1.24) est disponible : [télécharger l’installateur Windows](https://github.com/creezio/pegolotti-gpt-releases/releases/download/v0.1.24/PegolottiGPT-Setup-0.1.24.exe).

Le catalogue, les logos et les liens de connexion Gmail/Notion ont passé la recette réelle de la 0.1.23. La 0.1.24 corrige la reprise automatique des services après une installation depuis un état « quitté » ; ses 2 135 contrôles natifs et son paquet passent les vérifications. Son démarrage réel sur le poste pilote reste à confirmer. Cette version n’est pas publiée comme version stable.

Les versions qualifiées seront disponibles dans [Releases](https://github.com/creezio/pegolotti-gpt-releases/releases).
